# **App Name**: Family Finance Flow

## Core Features:

- Expense Tracking: Track family expenses by category and date.
- Budgeting: Set monthly budgets for different spending categories.
- Bill Management: Manage and track bill payments, due dates, and payment status, using the Firestore database.
- Paycheck Bill Highlighting: Calls out which bills are due within each paycheck period (every two weeks beginning 1/2/2026).
- Financial Goal Setting: Define financial goals and track progress toward achieving them.
- Report Generation: Generate reports on spending, budgeting, and financial goal progress.
- AI-Powered Spending Insights: Use a tool to provide personalized insights and recommendations based on spending patterns.
- User Authentication: Secure user accounts with login and authentication features.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to convey trust and stability.
- Background color: Very light indigo (#F0F2F9) for a clean, calming backdrop.
- Accent color: Vibrant purple (#7E57C2) for highlights and interactive elements.
- Body: 'PT Sans', a humanist sans-serif, combining a modern look and a little warmth or personality, suitable for body text. Headline: 'Playfair', A modern sans-serif similar to Didot, geometric, high contrast thin-thick lines, with an elegant, fashionable, high-end feel, suitable for headlines. A code font is not required.
- Use simple, outline-style icons from Lucide to represent categories and actions.
- Use a clean, grid-based layout to present information clearly and intuitively.
- Incorporate subtle animations, like transitions, to enhance the user experience and provide feedback.
